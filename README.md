# CyberSlide Builder | 网络安全培训课件生成系统

CyberSlide Builder 是一款遵循极致简约美学设计的全栈式 PPT 替代方案。允许教育者通过内置 Agentic 一键生成，或手工粘贴 AI 生成的 HTML 代码块，快速构建、预览并导出可交互的、离线运行的单文件演示文稿。

## 🚀 核心功能

- **Agentic 一键生成**：输入一句主题需求，内置大模型自动规划大纲，并行渲染生成多页极简具有动效的代码。
- **自定义主题 (Themes)**：内置 "暗物质"、"毛玻璃海洋"、"赛博朋克" 等数十种精美主题。
- **多平台大模型接入**：支持 OpenAI, Gemini, DeepSeek 以及本地模型配置。
- **企业 Logo 管理**：支持上传公司 Logo 并在单页内强制避让其空间。
- **幻灯片全生命周期管理**：支持拖拽排序、实时编辑、重命名、自动保存、快速复制克隆等功能。

## 📖 使用指南

1. **项目命名**：在顶部标题栏直接点击即可修改项目名称。
2. **大模型配置**：首先点击右上角的 **大模型配置 (Settings)** 填入您的 API Key。
3. **Agent 一键生成**：
    - 点击左下角的 **Agentic 一键生成** 按钮。
    - 输入您的需求，确认大纲后，即可自动生成全部幻灯片。
4. **幻灯片管理**：
    - 点击左侧栏的 `+` 添加新页面，点击 `Copy` 克隆常用排版，点击 `Trash` 删除。
    - 拖拽左侧幻灯片可快速调整幻灯片顺序。
5. **深入编辑与完善**：
    - 在 **预览模式** 下，双击文本即可进行内容修改。
    - 在 **代码编辑 (Code)** 模式下，直接修改底层 HTML。
6. **个性化 UI**：
    - 点击 **企业 Logo (图片图标)** 上传并选定您或公司的水牌。
    - 选择顶部的主题切换器更改全局色彩氛围。
7. **一键导出**：
    - 点击左下角“导出演示文稿”，您将得到一个脱离平台也能离线、全屏完美播放的 `.html` 独立文件。

## 🤖 代码生成与自定义

为了兼容系统，如果是自己外部粘贴代码，请确保：
1. **沙盒隔离**：禁止输出外层 `<html>/<body>` 等骨架结构。
2. **样式控制**：使用原生 Tailwind CSS 进行排版，禁止引用外部资源。
3. **安全处理**：使用 `(function(){})()` 闭包控制 JS，类名加前缀防污染页面结构。
